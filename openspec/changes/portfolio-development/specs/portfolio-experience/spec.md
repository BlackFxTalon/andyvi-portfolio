# Portfolio Experience

## Purpose

Help visitors evaluate the owner's specialization and verified work and get in touch across devices.

## ADDED Requirements

### Requirement: Responsive layout
The site MUST keep main content and form controls accessible without clipping or horizontal page scrolling from 320 to 1920 CSS pixels and at 200% zoom.

#### Scenario: Narrow viewport
- **WHEN** a visitor opens a page at 320 or 390 CSS pixels
- **THEN** content is readable and form controls remain accessible.

### Requirement: Verified information and contacts
The site MUST display confirmed contacts, experience dates, and numerical claims.

#### Scenario: Contact link
- **WHEN** a visitor selects email or Telegram
- **THEN** the confirmed address of the owner is opened.

### Requirement: Contact form
The form MUST explain errors and retain entered data on failure; valid requests MUST reach the configured owner.

#### Scenario: Delivery failure
- **WHEN** delivery fails
- **THEN** the visitor receives an understandable error and retains the entered data.

### Requirement: Project cases
The site MUST present verified projects, actionable links, separate pages for agreed cases, and a way to discuss similar work.

#### Scenario: Private project
- **WHEN** a project has no public demo or is subject to NDA
- **THEN** the site explains the restriction without disclosing private information.
